# PostgreSQL Inventory

Learning project for studying PostgreSQL through a simple inventory application.

## Current Progress

- PostgreSQL 18
- Created `inventory` database
- Created `products` table
- Practiced `INSERT`
- Practiced `SELECT`

## Current Database Structure

### products

| Column       | Type          | Constraint            |
| ------------ | ------------- | --------------------- |
| product_id   | INTEGER       | Primary Key, Identity |
| product_name | TEXT          | NOT NULL              |
| price        | NUMERIC(12,2) | NOT NULL              |
| stock        | INTEGER       | NOT NULL              |

## Learning Path

This project will gradually grow into a web-based inventory application using:
